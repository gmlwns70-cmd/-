# 청남대 웰니스타운 산삼고추장·산삼된장 특가 랜딩 페이지

스마트스토어와 별도로, 정해진 기간에만 운영하는 특가 행사용 페이지입니다. `index.html` 파일 하나로 동작합니다.

## 수정하는 곳
`index.html` 맨 아래 `<script>` 안의 **CONFIG** 만 고치면 됩니다.

| 항목 | 설명 |
|---|---|
| `draft` | 확정 전 `true`(상단 경고 표시) → 오픈 시 `false` |
| `startAt` / `endAt` | 행사 시작·종료 (한국시간 `+09:00`). 종료되면 주문 버튼이 자동으로 막힙니다 |
| `products` | 정가 `regular` / 행사가 `sale`, 용량, 설명 |
| `options` | 단품·세트 구성. 세트는 `price` 로 세트가 지정 |
| `shippingFee` / `freeShippingOver` | 배송비, 무료배송 기준 금액 |
| `kakaoUrl` / `orderUrl` / `phone` / `bank` | 주문 받는 곳. 비워 두면 해당 버튼이 숨겨집니다 |
| `productInfo` / `business` | 상품정보 고시·사업자 정보 (`[입력 필요]` 모두 채우기) |

※ 들어 있는 가격·기간은 **예시**입니다.

## 사진
`images/gochujang.jpg`, `images/doenjang.jpg` (정사각형 권장)를 넣으면 항아리 그림 대신 자동으로 표시됩니다.
카톡 공유 미리보기는 `images/og.jpg` (1200×630).

## 주문 흐름
고객이 수량 선택 → "주문서 작성하기" → 주문 내용이 복사되고 카카오톡 채널(또는 폼)이 열림 → 붙여넣고 받는 분 정보 작성 → 입금 확인 후 발송.

## 올리는 방법
GitHub Pages, Netlify Drop(폴더를 끌어다 놓기), 또는 쓰고 계신 호스팅에 `cheongnamdae-sansam` 폴더를 통째로 올리면 됩니다.
