# 청남대 웰니스타운 산삼고추장·산삼된장 — 효도 선물 특가 랜딩 페이지

'건강기원형' 컨셉의 기간 한정 특가 페이지입니다. 스마트스토어와 별도로 운영합니다.
`index.html` 파일 하나로 동작하며, **코드를 몰라도 화면에서 사진과 정보를 직접 넣을 수 있습니다.**

## 직접 고치는 방법 (편집 모드)
1. `index.html` 을 크롬(또는 엣지)으로 엽니다.
2. 맨 위 **"편집 모드 열기 →"** 를 누르거나, 주소창 끝에 `#edit` 를 붙여 엔터.
3. 오른쪽 편집창에서 차례로 채웁니다.
   - ① 기본 정보·행사 기간 ② **사진 넣기** ③ 상품·가격 ④ 판매 구성(세트) ⑤ 주문 받는 곳·배송비
   - ⑥ 메시지 카드 ⑦ 페이지 문구 ⑧ 상품정보 고시 ⑨ 사업자 정보 ⑩ 주문 절차·FAQ
   - 페이지의 사진 자리를 눌러도 바로 사진을 넣을 수 있습니다.
   - 빨간 칸 = 아직 비어 있는 필수 항목. **"빈칸 찾기"** 로 하나씩 이동합니다.
4. 다 채웠으면 ①의 **"초안 표시"** 체크를 해제합니다 (점선 안내 상자가 사라짐).
5. **"완성 파일 내려받기"** → 새 `index.html` 이 저장됩니다. 사진까지 이 파일 하나에 들어 있습니다.

> 작업 중인 내용은 브라우저에 자동 임시 저장되어, 창을 닫았다 열어도 이어서 편집할 수 있습니다.
> 단, 최종본은 꼭 "완성 파일 내려받기"로 저장하세요.

## 준비할 사진 (10장 + 로고 선택)
| 자리 | 추천 사진 | 비율 |
|---|---|---|
| 메인(첫 화면) | 한옥 창가 햇살 + 김 나는 밥상 위 고추장·된장 | 16:9 가로 |
| 공감 | 부모님의 손이 정갈하게 식사하는 모습 | 21:9 와이드 |
| 산양삼 | 흙 묻은 굵은 산양삼 뿌리 클로즈업 | 4:5 세로 |
| 장독대 | 햇볕 아래 장독대 | 1:1 |
| 밥상 | 뚝배기에서 끓는 찌개, 갓 지은 밥 | 21:9 와이드 |
| 산삼고추장 / 산삼된장 | 제품 단독 컷, 밝은 배경 | 1:1 |
| 청남대 풍경 | 대청호와 청남대 자연 | 21:8 와이드 |
| 제조 시설 | 위생적인 제조·숙성 공간 | 4:3 |
| 선물세트 | 보자기 또는 나무 상자 포장 | 4:5 세로 |

큰 사진도 자동으로 알맞게 줄여서 넣습니다. 아이폰 HEIC 사진은 JPG로 바꿔서 넣어 주세요.

## 페이지 흐름
첫 화면(위로와 혜택·카운트다운) → 공감(부모님 입맛 걱정) → 솔루션(왜 산삼과 장인가) → 상품 → 신뢰(원재료·품질 관리) → 효도 선물 → 주문(구성 선택 + **메시지 카드**) → 주문 방법·입금 계좌 → FAQ·상품정보 고시 → 사업자 정보

## 주문 흐름
고객이 구성·카드 문구 선택 → "카카오톡으로 주문하기"(또는 주문서 작성하기) → 주문 내용과 카드 문구가 복사되고 카카오톡 채널/주문폼이 열림 → 붙여넣고 받는 분 정보 작성 → 입금 확인 후 발송.
행사 종료 시각이 지나면 주문 버튼이 자동으로 닫힙니다.

## 올리는 방법
완성된 `index.html` 하나만 올리면 됩니다. (예: Netlify Drop 에 파일 끌어다 놓기, GitHub Pages, 사용 중인 호스팅)

## 문구 주의 (식품표시광고법)
- 식품에 "면역력 강화, 질병 예방·치료, 흡수율 향상" 같은 효능 표현은 쓸 수 없습니다.
- "7년근", "100% 국산" 같은 수치·원산지 표현은 실제 라벨·증빙과 일치해야 합니다.
- 인증(HACCP 등)은 실제 보유한 것만 ⑦ 페이지 문구 › 인증·수상 칸에 적어 주세요.
