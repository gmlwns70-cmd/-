# 산마루랩 홈페이지

농부가 만드는 농가 디지털 성장 파트너, 산마루랩의 원페이지 홈페이지입니다.
설치할 프로그램이 없는 순수 HTML·CSS·JavaScript 사이트입니다.

## 파일 구조

| 파일 | 하는 일 | 고칠 일이 있나요? |
|---|---|---|
| `content.js` | 가격·연락처·사례·소개 문구 | **자주 고칩니다** |
| `images/` | 사진, 공유 미리보기 이미지 | 사진을 넣을 때 |
| `index.html` | 페이지 뼈대, 검색·공유 정보 | 사이트 주소가 바뀔 때만 |
| `style.css` | 디자인(색·글꼴·배치) | 거의 없음 |
| `main.js` | 메뉴, 카드 펼치기, 나타나기 효과 | 거의 없음 |

## 내용 고치기

1. `content.js`를 메모장(윈도우)이나 텍스트 편집기(맥)로 엽니다.
2. 큰따옴표 `" "` 안의 글자만 바꿉니다. 줄 끝의 쉼표는 지우지 않습니다.
3. `[가격]`, `[연락처]`처럼 대괄호로 된 곳은 아직 비어 있는 자리입니다.
   화면에서는 노란 표시로 보이고, 실제 내용을 쓰면 표시가 사라집니다.
4. 저장한 뒤 브라우저를 새로고침합니다.

## 사진 넣기

`images` 폴더에 아래 이름으로 사진을 넣으면 회색 자리표시 상자 대신 사진이 보입니다.

- `ceo-hero.jpg` – 첫 화면 대표 사진 (세로 4:5 비율 권장)
- `ceo-about.jpg` – 대표 소개 사진 (세로 4:5 비율 권장)

빠르게 열리도록 사진은 **가로 1000px 안팎, 300KB 이하**로 줄여서 넣어 주세요.
(무료 사이트 https://squoosh.app 에서 사진을 끌어다 놓고 크기를 줄일 수 있습니다.)

`og-image.png`는 카카오톡·SNS로 링크를 보낼 때 보이는 미리보기 이미지입니다(1200×630).
다른 이미지로 바꾸려면 같은 이름, 같은 크기로 덮어쓰면 됩니다.

## 내 컴퓨터에서 미리보기

`docs` 폴더 안의 `index.html`을 더블클릭하면 브라우저에서 열립니다.
글꼴은 인터넷에서 받아 오므로 인터넷이 연결되어 있어야 디자인 그대로 보입니다.

휴대폰 화면으로 보려면 크롬에서 `F12` → 왼쪽 위 휴대폰 모양 아이콘을 누르고,
화면 크기를 `390`으로 맞추면 됩니다.

## GitHub Pages 배포 (무료)

1. 이 작업 브랜치를 `main` 브랜치에 합칩니다(Pull Request 병합).
2. GitHub 저장소 화면 → **Settings** → 왼쪽 **Pages**.
3. **Source**: `Deploy from a branch` 선택.
4. **Branch**: `main`, 폴더는 `/docs` 선택 → **Save**.
5. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나옵니다.
   (이 저장소 이름 기준: `https://gmlwns70-cmd.github.io/-/`)
6. 주소가 다르면 `index.html` 위쪽의 `canonical`, `og:url`, `og:image` 세 곳의 주소를 실제 주소로 바꿉니다.

이후에는 `content.js`를 고쳐 `main`에 올리기만 하면 1~2분 안에 사이트에 반영됩니다.
