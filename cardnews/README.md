# 📱 인스타그램 카드뉴스 자동 제작기

주제 한 줄만 넣으면 아래 결과물을 자동으로 만들어 주는 프로그램이에요.

- 1080×1350px(4:5) 카드 이미지 10~15장 (약 40%는 일러스트 카드)
- 인스타 캡션 본문 + 해시태그 15개 (`caption.txt`)
- 숫자·통계의 출처 목록 (`sources.md`)
- 원고 파일 (`script.json`) — 이 파일만 고쳐서 카드를 다시 만들 수 있어요

> 코딩을 몰라도 괜찮아요. 아래 순서대로 **하나씩 따라 하기만** 하면 됩니다.

---

## 🖱️ 가장 쉬운 방법: 대시보드 (클릭만으로 사용)

1. `cardnews` 폴더에서 **`run_dashboard.bat`** 을 **더블클릭**해요. (Mac: `run_dashboard.command`)
   - 처음 한 번은 설치하느라 몇 분 걸려요. 검은 창은 **닫지 말고** 그대로 두세요.
2. 인터넷 창(브라우저)에 대시보드가 자동으로 열려요. 안 열리면 주소창에 `http://localhost:8502` 를 입력하세요.
3. **① 만들기** 탭: 주제를 쓰고 **🚀 카드뉴스 만들기** 를 눌러요.
4. **② 결과 보기·다운로드** 탭: 카드를 보고 **⬇️ ZIP 받기** 를 누르면 카드 전체와 캡션을 한 번에 받아요. 캡션은 복사 버튼으로 바로 복사할 수 있어요.
5. **③ 문구 고치기** 탭: 카드 문구를 고치고 **💾 저장하고 다시 만들기** 를 눌러요. (줄 앞에 `*` = 노란 형광펜)

> API 키는 처음 한 번만 `.env` 파일에 넣으면 돼요. 대시보드 왼쪽 **준비 상태** 에서 키가 들어갔는지 확인할 수 있어요. ([3단계](#3단계-api-키-넣는-법) 참고)
> 파이썬이 없다면 [1단계](#1단계-파이썬-설치-처음-한-번만)만 먼저 해 주세요.

## 1단계: 파이썬 설치 (처음 한 번만)

**Windows**
1. https://www.python.org/downloads/ 에서 **Download Python 3.x** 버튼을 눌러 내려받습니다.
2. 설치 파일을 실행하고, 첫 화면 맨 아래 **☑ Add python.exe to PATH** 를 **꼭 체크**합니다. ← 가장 중요해요!
3. **Install Now** 를 누르고 끝날 때까지 기다립니다.

**Mac**
1. https://www.python.org/downloads/ 에서 macOS 설치 파일을 내려받아 실행합니다.

> **확인 방법**
> - Windows: 시작 메뉴에서 `cmd` 를 검색해 "명령 프롬프트"를 열고 `python --version` 입력
> - Mac: "터미널" 앱을 열고 `python3 --version` 입력
>
> `Python 3.11.x` 처럼 숫자가 나오면 성공이에요.

> 💡 이 설명에서 `python` 이라고 쓴 곳은 **Mac에서는 `python3`** 로 바꿔 입력하세요.

## 2단계: 프로그램 설치 (처음 한 번만)

1. 명령 프롬프트(Mac은 터미널)를 엽니다.
2. `cd` 명령으로 이 `cardnews` 폴더로 이동합니다.
   ```
   cd 바탕화면\카드뉴스폴더\cardnews
   ```
   > 팁: `cd ` (cd 뒤에 한 칸 띄우기)까지 입력하고, `cardnews` 폴더를 창 안으로 끌어다 놓으면 경로가 자동으로 들어가요.
3. 이 프로그램만 쓰는 "가상환경"을 만들고 켭니다. (컴퓨터 전체에는 아무것도 설치하지 않아요)
   - Windows
     ```
     python -m venv .venv
     .venv\Scripts\activate
     ```
   - Mac
     ```
     python3 -m venv .venv
     source .venv/bin/activate
     ```
   줄 맨 앞에 `(.venv)` 가 보이면 성공이에요.
4. 필요한 부품을 설치합니다. (1~3분)
   ```
   pip install -r requirements.txt
   ```
5. 잘 설치됐는지 **API 키 없이** 샘플을 만들어 봅니다.
   ```
   python main.py sample
   ```
   `output/sample` 폴더에 카드 이미지가 생기면 성공! 🎉
   (처음 한 번은 글꼴 Pretendard를 자동으로 내려받느라 조금 걸려요.)

> ⚠️ 다음에 프로그램을 쓸 때도 **3번의 두 번째 줄(가상환경 켜기)** 은 매번 먼저 실행해 주세요.

## 3단계: API 키 넣는 법

API 키는 "이 프로그램이 AI 서비스를 쓸 수 있게 해 주는 비밀번호"예요. **절대 다른 사람에게 보여주거나 인터넷에 올리지 마세요.**

### ① `.env` 파일 만들기
`cardnews` 폴더 안의 `.env.example` 파일을 복사해서 이름을 **`.env`** 로 바꿉니다.
- Windows: 명령 프롬프트에서 `copy .env.example .env`
- Mac: 터미널에서 `cp .env.example .env`

그다음 `.env` 를 메모장(Mac은 텍스트 편집기)으로 엽니다.

### ② Claude API 키 (필수: 원고 작성 + 사실 검증)
1. https://console.anthropic.com 에 가입하고 로그인합니다.
2. 결제 수단(Billing)을 등록합니다. (사용한 만큼 요금이 나가요)
3. **API Keys → Create Key** 를 눌러 키를 만들고 복사합니다. (`sk-ant-` 로 시작해요)
4. `.env` 의 `ANTHROPIC_API_KEY=` 뒤에 붙여넣습니다. **따옴표 없이, 띄어쓰기 없이!**
   ```
   ANTHROPIC_API_KEY=sk-ant-여기에붙여넣기
   ```

### ③ 이미지 API 키 (선택: 일러스트)
일러스트가 필요 없으면 `IMAGE_PROVIDER=none` 그대로 두세요. 글자만 있는 카드로 만들어져요.

일러스트를 넣으려면 둘 중 **하나만** 고르면 돼요.

| 선택 | `.env` 에 쓸 내용 | 키 받는 곳 |
|---|---|---|
| OpenAI | `IMAGE_PROVIDER=openai`<br>`OPENAI_API_KEY=키` | https://platform.openai.com/api-keys |
| Google Gemini | `IMAGE_PROVIDER=gemini`<br>`GEMINI_API_KEY=키` | https://aistudio.google.com/apikey |

저장(Ctrl+S / Cmd+S)하면 끝이에요.

> 🔒 프로그램은 키를 `.env` 에서만 읽고, 화면이나 기록에 키 값을 절대 출력하지 않아요.

## 4단계: 실행 순서

가상환경을 켠 상태(`(.venv)` 보이는 상태)에서 입력합니다.

### ① 카드뉴스 만들기
```
python main.py --topic "줄 서던 가게가 금방 조용해지는 이유" --target "자영업 사장님" --cards 15
```
- `--brand "@내계정"` 을 붙이면 표지에 계정명이 들어가요.
- `--text-only` 를 붙이면 이미지 API 키가 있어도 일러스트 없이 만들어요.

진행 과정이 화면에 순서대로 나와요.
```
[1/5] 자료 조사 (웹 검색으로 실제 수치 찾기)
[2/5] 원고 작성
[3/5] 수치 검증
[4/5] 일러스트
[5/5] 카드 합성
```
3~10분쯤 걸려요. (일러스트를 만들면 더 걸려요)

### ② 결과 확인
`output/날짜_주제` 폴더가 생겨요. 예: `output/2026-11-12_줄_서던_가게가_금방_조용해지는_이유`

| 파일 | 내용 |
|---|---|
| `card_01.png` ~ | 인스타에 올릴 카드 이미지 |
| `caption.txt` | 캡션 본문 + 저장·공유 유도 문장 + 해시태그 15개 |
| `sources.md` | 숫자 출처 목록 (**올리기 전 링크를 꼭 한 번씩 열어 보세요**) |
| `script.json` | 원고 (고쳐서 다시 만들 때 사용) |
| `check_report.md` | 자동 검수 결과 |
| `images/` | 생성된 일러스트 원본, `reference.png`(캐릭터 기준 이미지) |

### ③ 검수 리포트 보기
```
python main.py check output/2026-11-12_줄_서던_가게가_금방_조용해지는_이유
```
아래 네 가지를 알려 줘요.
- 맞춤법 의심 표현 (자주 틀리는 표현, 해요체가 아닌 문장)
- 출처 없는 수치
- 한 줄 글자 수 초과
- 글자와 인물 겹침 (대략적으로 판단)

> 💡 폴더 경로가 길면 `check ` 까지 입력하고 폴더를 창에 끌어다 놓으세요.

## ✏️ 원고 고치고 다시 만들기

문구가 마음에 안 들면 **`script.json` 만 고치고** 아래 명령을 실행하세요. 일러스트는 다시 만들지 않아서 돈과 시간이 들지 않아요.

```
python main.py render output/2026-11-12_줄_서던_가게가_금방_조용해지는_이유
```

`script.json` 을 메모장으로 열면 카드마다 이런 부분이 있어요.
```json
"lines": [
  {"text": "손님이 다시 오는 건", "highlight": false},
  {"text": "기억에 남았기", "highlight": true}
]
```
- `"text"` : 한 줄에 들어갈 글 (한 줄 13자 안팎 권장)
- `"highlight": true` : 그 줄에 노란 형광펜
- `{"text": "", "highlight": false}` : 빈 줄 (문장 덩어리 사이 간격)
- 캡션을 고치려면 맨 아래 `"caption"` 부분을 고치면 `caption.txt` 도 다시 만들어져요.

> ⚠️ 따옴표(`"`)와 쉼표(`,`)를 지우지 않게 조심하세요. 하나라도 빠지면 오류가 나요.

**일러스트 한 장만 바꾸고 싶을 때:** `images` 폴더에서 그 카드의 그림(예: `card_04.png`)을 지우고 아래 명령을 실행하세요. 지운 그림만 새로 만들고 카드를 다시 합성해요. (`reference.png` 는 지우지 마세요. 캐릭터 기준이에요.)
```
python main.py images output/2026-11-12_줄_서던_가게가_금방_조용해지는_이유
```
갖고 있는 그림 파일을 같은 이름으로 넣고 `render` 를 실행해도 돼요.

## ⚙️ 설정 바꾸기 (`config.yaml`)

메모장으로 열어 값을 바꾸고 저장하면 다음 실행부터 적용돼요.

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `topic`, `target`, `brand`, `cards` | 주제·타깃·계정명·장수 (명령어에 쓴 값이 우선) | |
| `character` | 모든 일러스트에 나오는 고정 캐릭터 | 30대 한국인 여성 사장님… |
| `claude.model` | 원고를 쓰는 AI 모델 | `claude-opus-5-5` |
| `claude.effort` | 생각의 깊이 (`low`~`max`, 높을수록 품질↑ 비용↑) | `high` |
| `style.text_size` | 텍스트 카드 글자 크기 | 70 |
| `style.min_size` | 넘칠 때 이 크기까지만 줄이고 경고 | 52 |
| `style.illustration_ratio` | 일러스트 카드 비율 | 0.4 |

종이 질감을 바꾸고 싶으면 `assets/paper.png` 를 지우세요. 다음 실행 때 새로 만들어요.

## 🔍 사실 검증 원칙

이 프로그램은 **숫자를 지어내지 않도록** 세 겹으로 막아요.

1. **자료 조사:** Claude가 웹 검색을 하고, 검색 결과에 실제로 나온 주소(URL)의 자료만 인정해요.
2. **숫자 대조:** 카드에 쓴 숫자가 그 자료에 그대로 있는지 프로그램이 한 번 더 확인해요.
3. **안 맞으면:** 숫자 없이 다시 쓰게 하고, 그래도 남으면 숫자가 든 줄을 빼고 그 카드에 "검증 필요" 표시를 붙여요. (`sources.md` 맨 아래에 적혀요)

데이터 카드에는 "OO에 따르면"처럼 출처가 본문에 들어가요.

> ⚠️ 그래도 AI가 페이지 내용을 잘못 읽을 수 있어요. **올리기 전에 `sources.md` 의 링크를 직접 열어 숫자를 꼭 확인**해 주세요.

## 🖼️ 일러스트 원칙
- 한국 웹툰풍 세미리얼, 깔끔한 펜 선, 따뜻한 수채 채색. 배경 없이 인물과 소품만 그려요.
- 첫 그림을 `images/reference.png` 로 저장하고, 다음 그림마다 참조로 넣어 같은 캐릭터를 유지해요.
- 감정은 장면마다 달라요 (당황·기대·걱정·고민·미소).
- 그림 안에 글자·워터마크·실존 브랜드 로고를 넣지 않고, 특정 작가나 계정의 캐릭터를 따라 하지 않도록 지시해요.
- 그림 생성이 실패하면 그 카드는 글자 카드로 대신 만들어져요. 전체 작업은 멈추지 않아요.

## 🆘 자주 생기는 문제

| 화면에 나온 말 | 해결 방법 |
|---|---|
| `'python'은(는) 내부 또는 외부 명령...이 아닙니다` | 파이썬 설치 때 **Add python.exe to PATH** 체크를 안 한 거예요. 파이썬을 다시 설치하며 체크하세요. |
| `No module named ...` | 가상환경을 안 켰거나 설치를 안 했어요. 2단계 3~4번을 다시 하세요. |
| `.env 파일에 ANTHROPIC_API_KEY 가 없어요` | `.env` 파일 이름이 정확한지(`.env.txt` 아님!), 키를 붙여넣고 저장했는지 확인하세요. Windows에서는 탐색기 **보기 → 파일 확장명** 을 켜면 진짜 이름이 보여요. |
| `Claude API 키가 올바르지 않습니다` | 키를 다시 복사해서 붙여넣으세요. 앞뒤 공백이 들어가지 않았는지도 확인하세요. |
| `요청이 너무 많습니다` | 1~2분 뒤 다시 실행하세요. |
| `일러스트 생성 실패` | 이미지 API 키와 `IMAGE_PROVIDER` 값을 확인하세요. 카드는 글자 카드로 만들어져 있어요. |
| `Pretendard 폰트를 내려받지 못했습니다` | https://github.com/orioncactus/pretendard/releases 에서 받아 `Pretendard-ExtraBold.otf` 를 `fonts` 폴더에 넣으세요. |
| 검수에서 "최소 크기에서도 글이 넘쳐요" | 그 카드의 줄 수를 줄이고 `render` 로 다시 만드세요. |

## 📁 폴더 구조 (참고)
```
cardnews/
├─ run_dashboard.bat  더블클릭하면 대시보드가 열려요 (Mac: run_dashboard.command)
├─ app.py             대시보드 화면
├─ main.py            실행 파일
├─ config.yaml        설정
├─ .env               API 키 (직접 만들기, 절대 공유 금지)
├─ requirements.txt   필요한 부품 목록
├─ cardmaker/         프로그램 본체
├─ assets/paper.png   종이 질감 (자동 생성)
├─ fonts/             Pretendard 글꼴 (자동 다운로드, SIL OFL 1.1)
└─ output/            결과물
```
