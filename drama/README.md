# 💕 숏폼 로맨스 드라마 — 대본 → 컷 프롬프트 생성기

아이디어 **한 줄**을 넣으면 Claude가 아래를 자동으로 만들어 줍니다.

1. **시리즈 설정집**: 제목, 등장인물(고정 외모), 회차별 줄거리
2. **회차별 촬영 대본**: 3~8초짜리 **컷** 단위로 나뉜 대본
3. **뉴테이크에 바로 붙여넣는 프롬프트**: 컷마다 영상 프롬프트와 시작 이미지 프롬프트

영상은 이 프롬프트를 **뉴테이크**에 붙여넣어 만듭니다.
뉴테이크의 공식 API가 확인되면 붙여넣는 단계까지 자동화할 수 있어요.

---

## 1. 처음 한 번만: 설치

> 파이썬 설치는 상위 폴더의 [README.md 1단계](../README.md#1단계-파이썬-설치-처음-한-번만)를 따라 하세요.

1. 명령 프롬프트(Windows)나 터미널(Mac)을 엽니다.
2. 이 `drama` 폴더로 이동합니다.
   ```
   cd 바탕화면\프로그램폴더\drama
   ```
   > 팁: `cd `(cd 뒤에 한 칸 띄우기)까지 입력한 다음, `drama` 폴더를 창 안으로 끌어다 놓으면 경로가 자동으로 들어가요.
3. 필요한 프로그램을 설치합니다.
   ```
   pip install -r requirements.txt
   ```
4. **키 없이 미리보기**로 잘 설치됐는지 확인합니다.
   ```
   python main.py sample
   ```
   `✅ 완성!`이 나오면 성공입니다. `output` 폴더에 예시 드라마 「우산은 하나뿐」이 생겨요.

## 2. API 키 넣기

1. `drama` 폴더의 `.env.example` 파일을 복사해서 이름을 **`.env`** 로 바꿉니다.
   - Windows: `copy .env.example .env`
   - Mac: `cp .env.example .env`
2. https://console.anthropic.com 에 로그인한 뒤 **API Keys → Create Key** 를 누릅니다.
3. `.env`를 메모장으로 열고, `ANTHROPIC_API_KEY=` 뒤에 키를 붙여넣고 저장합니다. **따옴표 없이, 띄어쓰기 없이!**

> 🔒 `.env`는 절대 다른 사람에게 보내지 마세요. 프로그램은 키 값을 화면에 출력하지 않습니다.

## 3. 드라마 만들기

```
python main.py --idea "비 오는 날 우산 하나로 엮인 꽃집 사장과 건축가" --episodes 3 --seconds 60
```

| 옵션 | 뜻 | 기본값 |
|---|---|---|
| `--idea` | 한 줄 아이디어 | (필수) |
| `--episodes` | 회차 수 (1~20) | 3 |
| `--seconds` | 한 회 길이(초) | 60 |
| `--genre` | 장르 | 로맨스 |

Windows에서는 **`드라마만들기.bat`** 를 더블클릭하고 아이디어만 입력해도 됩니다.

한 회에 1~2분쯤 걸립니다. 더 자주 바꾸는 값(화풍, 컷 길이 등)은 `config.yaml`을 메모장으로 열어 고치세요.

## 4. 결과물과 뉴테이크에서 쓰는 순서

`output/날짜_제목/` 폴더에 다음 파일이 생깁니다.

| 파일 | 용도 |
|---|---|
| `01_인물설정표.md` | 인물 소개와 **기준 이미지 프롬프트** |
| `02_대본_EP01.md` | 사람이 읽기 좋은 대본 (초 단위 타임라인 포함) |
| `03_컷목록_EP01.csv` | 엑셀로 여는 컷 표. 마지막 "상태" 칸에 진행 상황을 적으며 관리 |
| `04_뉴테이크_프롬프트_EP01.txt` | 컷별로 복사해서 붙여넣는 프롬프트 |
| `검수.txt` | 길이와 대사량 자동 검사 결과 |
| `series.json` | 모든 데이터 원본 (고친 뒤 다시 내보낼 때 사용) |

**뉴테이크 작업 순서**
1. `01_인물설정표.md`의 기준 이미지 프롬프트로 인물마다 **얼굴 이미지 한 장**을 만들어 저장합니다.
2. `04_뉴테이크_프롬프트_EP01.txt`를 열고, 컷 1부터 순서대로 진행합니다.
   - **[시작 이미지 프롬프트]** 와 인물 기준 이미지로 첫 장면 이미지를 만듭니다.
   - 그 이미지에 **[영상 프롬프트]** 를 넣어 영상으로 만들고, 길이는 표에 적힌 "초"에 맞춥니다.
3. 대사는 TTS(음성 합성)로 만들고, 컷 영상을 순서대로 이어 붙이면 한 회가 완성됩니다.

> 💡 같은 얼굴이 계속 나오게 하는 비결: 모든 프롬프트 앞에 인물의 **고정 외모 문장**이 자동으로 붙어 있습니다. 여기에 기준 이미지까지 참조로 넣으면 인물 일관성이 크게 좋아져요.

## 5. 대본을 고치고 싶을 때

1. 결과 폴더의 `series.json`을 메모장으로 열어 대사나 프롬프트를 고칩니다. (따옴표와 쉼표는 지우지 마세요)
2. 아래 명령으로 다시 내보냅니다. API 비용은 들지 않아요.
   ```
   python main.py export output/2026-11-18_우산은_하나뿐
   ```

## 자주 생기는 문제

| 메시지 | 해결 |
|---|---|
| `.env 파일에 ANTHROPIC_API_KEY 가 없어요` | 파일 이름이 `.env.txt`가 아니라 `.env`인지 확인하세요. 탐색기에서 **보기 → 파일 확장명**을 켜면 진짜 이름이 보여요. |
| `Claude API 키가 올바르지 않습니다` | 키를 끝까지 복사했는지, 앞뒤에 공백이 없는지 확인하세요. |
| `대본이 너무 길어 중간에 끊겼습니다` | `--seconds` 값을 줄이거나 한 번 더 실행하세요. |
| `⚠ 대사가 ...초 안에 말하기엔 길어요` | `series.json`에서 대사를 줄이거나 그 컷의 `seconds`를 늘린 뒤 `export` 하세요. |
