# 🎬 유튜브 영상 자동 제작 도구

키워드 하나로 **트렌드 리서치 → 대본 → AI 내레이션 → 소재 매칭 → 자막 → 영상 조립**까지,
버튼 몇 번으로 **8~10분 가로 영상(16:9)** 과 **60초 쇼츠(9:16)** 를 만들어 주는 내 컴퓨터용 프로그램입니다.

> 코딩을 몰라도 괜찮아요. 아래 순서대로 **하나씩 따라 하기만** 하면 됩니다. (Windows 10/11 기준)

## 1단계: 파이썬 설치 (처음 한 번만)

1. https://www.python.org/downloads/release/python-3119/ 에 접속합니다.
2. 아래쪽 **Files** 목록에서 **Windows installer (64-bit)** 를 눌러 내려받습니다.
3. 내려받은 파일을 실행하고, 첫 화면 맨 아래의
   **☑ Add python.exe to PATH** 를 **꼭 체크**합니다. ← 가장 중요해요!
4. **Install Now** 를 누르고 끝날 때까지 기다립니다.

> 확인 방법: 시작 메뉴에서 `cmd` 를 검색해 "명령 프롬프트"를 열고 `python --version` 을 입력하세요.
> `Python 3.11.x` 처럼 나오면 성공이에요.

## 2단계: ffmpeg 설치 (처음 한 번만, 권장)

ffmpeg는 영상을 만들고 합치는 프로그램이에요.
(설치하지 않아도 프로그램 안에 들어 있는 ffmpeg로 동작하지만, 설치해 두면 더 안정적이에요.)

**방법 A — 명령어 한 줄 (추천)**
1. 시작 메뉴에서 `cmd` 를 검색해 **명령 프롬프트**를 엽니다.
2. 아래 줄을 복사해서 붙여넣고 Enter:
   ```
   winget install Gyan.FFmpeg
   ```
3. 설치가 끝나면 명령 프롬프트를 **닫았다가 다시 열고** `ffmpeg -version` 을 입력해 글자가 쭉 나오면 성공!

**방법 B — 직접 설치 (winget이 안 될 때)**
1. https://www.gyan.dev/ffmpeg/builds/ 에서 **ffmpeg-release-essentials.zip** 을 내려받습니다.
2. 압축을 풀고, 폴더 이름을 `ffmpeg` 로 바꿔 `C:\ffmpeg` 위치로 옮깁니다. (안에 `bin` 폴더가 있어야 해요)
3. 시작 메뉴에서 **"시스템 환경 변수 편집"** 을 검색해 엽니다.
4. **환경 변수** → 아래쪽 **시스템 변수**에서 `Path` 선택 → **편집** → **새로 만들기** → `C:\ffmpeg\bin` 입력 → 확인 3번.
5. 명령 프롬프트를 새로 열고 `ffmpeg -version` 으로 확인합니다.

## 3단계: 프로그램 설치 (처음 한 번만)

1. 이 프로그램 폴더를 원하는 곳(예: `바탕화면`)에 둡니다.
   - 폴더 경로에 한글이 있어도 대부분 괜찮지만, 문제가 생기면 `C:\youtube-maker` 같은 영어 경로로 옮겨 보세요.
2. 폴더 안의 **`install.bat`** 을 **더블클릭**합니다.
3. 검은 창에서 설치가 진행됩니다. (5~10분) **"설치 완료!"** 가 나오면 아무 키나 눌러 닫으세요.
4. (선택) 한글 폰트 넣기: [Pretendard](https://github.com/orioncactus/pretendard/releases) 를 받아
   `Pretendard-Bold.otf` 파일을 `fonts` 폴더에 넣으면 자막이 더 예뻐져요. 없으면 맑은 고딕을 씁니다.

## 4단계: API 키 받기

API 키는 "이 프로그램이 해당 서비스를 써도 된다"는 **비밀번호** 같은 거예요.
받은 키는 프로그램 폴더의 **`.env`** 파일(메모장으로 열기)에 붙여넣고 저장합니다.

```
ANTHROPIC_API_KEY=sk-ant-여기에붙여넣기
YOUTUBE_API_KEY=AIza여기에붙여넣기
```
> ⚠️ `=` 앞뒤에 띄어쓰기 없이, 따옴표 없이 넣으세요.
> ⚠️ `.env` 파일은 절대 다른 사람에게 보내거나 인터넷에 올리지 마세요.
> 💡 `.env` 파일이 안 보이면: 파일 탐색기 위쪽 **보기 → 표시 → 파일 확장명** 을 켜 보세요.

| 키 | 꼭 필요? | 어디에 쓰나 | 비용 |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | ✅ 필수 | 대본 생성 | 유료 (사용한 만큼) |
| `YOUTUBE_API_KEY` | 리서치할 때 | 트렌드 리서치 | 무료 (하루 한도 있음) |
| `PEXELS_API_KEY` | 둘 중 하나 권장 | 무료 스톡 영상·사진 | 무료 |
| `PIXABAY_API_KEY` | 둘 중 하나 권장 | 무료 스톡 영상·사진 | 무료 |
| `ELEVENLABS_API_KEY` | 선택 | 고품질 음성 | 유료 |
| `TYPECAST_API_KEY` | 선택 | 고품질 한국어 음성 | 유료 |

### 🔑 Claude API 키 (대본 생성)
1. https://console.anthropic.com 에 가입·로그인합니다.
2. **Settings → Billing** 에서 결제 수단을 등록하고 크레딧을 충전합니다. (5달러부터)
3. **API Keys → Create Key** → 이름 아무거나 → 생성된 `sk-ant-...` 키를 복사합니다. (한 번만 보여줘요!)
4. `.env` 의 `ANTHROPIC_API_KEY=` 뒤에 붙여넣습니다.

> 💰 기본 모델(`claude-sonnet-5-5`)로 10분 대본 한 편에 보통 수백 원 정도 들어요. (길이·설정에 따라 달라짐)
> 정확한 사용량은 콘솔의 **Usage** 메뉴에서 볼 수 있어요.

### 🔑 YouTube Data API 키 (리서치)
1. https://console.cloud.google.com 에 구글 계정으로 로그인합니다.
2. 위쪽 **프로젝트 선택 → 새 프로젝트** → 이름 입력 → 만들기.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → `YouTube Data API v3` 검색 → **사용** 버튼.
4. **API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키** → 복사.
5. `.env` 의 `YOUTUBE_API_KEY=` 뒤에 붙여넣습니다.

> 하루 무료 한도는 10,000 유닛이고, 검색 1번(결과 50개)에 약 100 유닛을 씁니다.

### 🔑 Pexels / Pixabay 키 (무료 스톡 소재)
- **Pexels**: https://www.pexels.com/api/ → 가입 → **Your API Key** 복사 → `PEXELS_API_KEY=`
- **Pixabay**: https://pixabay.com/api/docs/ → 가입·로그인 후 페이지 중간 **key** 부분 복사 → `PIXABAY_API_KEY=`

### 🔑 (선택) ElevenLabs / 타입캐스트
- **ElevenLabs**: https://elevenlabs.io → Profile → API Keys. 쓰고 싶은 목소리의 **Voice ID** 도 복사해 두세요.
- **타입캐스트**: https://typecast.ai 개발자 API 메뉴에서 키 발급. 캐릭터의 **Voice ID** 도 필요해요.
- Voice ID는 `config.yaml` 에 적어 두거나 프로그램 화면에서 입력할 수 있어요.

## 5단계: 실행하기

1. **`run.bat`** 을 더블클릭합니다.
2. 검은 창이 뜨고, 몇 초 뒤 인터넷 창(`http://localhost:8501`)이 자동으로 열려요.
   - 안 열리면 크롬 주소창에 `localhost:8501` 을 직접 입력하세요.
3. 다 쓰고 나면 **검은 창을 닫으면** 프로그램이 꺼져요.

> `.env` 나 `config.yaml` 을 고쳤다면 검은 창을 닫고 `run.bat` 을 다시 실행해야 적용돼요.

## 🧭 사용 방법

왼쪽 사이드바에서 **새 프로젝트**를 만들고(주제 입력 → 프로젝트 만들기), 위쪽 탭을 순서대로 진행하세요.
가장 쉬운 방법은 **⑦ 전체 자동 실행** 탭이에요.

| 탭 | 하는 일 |
|---|---|
| **① 리서치** | 키워드로 최근 인기 영상의 숫자를 모아 **구독자 대비 조회수 배율**, **일평균 조회수** 순으로 보여줘요. 제목 단어 TOP 20도 나와요. CSV로 저장할 수 있어요. |
| **② 대본** | 주제·길이·톤을 고르면 Claude가 대본을 새로 써요. **표에서 바로 고칠 수 있어요.** 다 고쳤으면 **💾 저장하고 확정**. |
| **③ 내레이션** | 목소리·속도를 고르고 **미리 듣기** → **전체 내레이션 만들기**. 장면별 길이가 자동 기록돼요. |
| **④ 소재** | 장면마다 ① 내 소재 → ② 허락 소재 → ③ Pexels/Pixabay 순서로 영상·사진을 찾아요. 출처는 `credits.txt` 에 자동 기록. |
| **⑤ 자막** | 글자 크기·테두리·위치를 미리보기로 맞추고 **자막 만들기**. SRT 파일도 저장돼요. |
| **⑥ 렌더링** | 배경음악·화질·쇼츠 여부를 고르고 **영상 만들기**. 완료되면 바로 재생해 볼 수 있어요. |
| **⑦ 전체 자동 실행** | 대본을 만든 뒤 **한 번 멈춰서** 확인을 받고, 나머지(③~⑥)를 자동으로 진행해요. |

### 중간부터 다시 하기
모든 결과물은 `projects/날짜_주제/` 폴더에 단계별로 저장돼요. 프로그램을 껐다 켜도
사이드바에서 프로젝트를 고르고 **⑦ 탭의 "이어서 실행"** 을 누르면 멈춘 곳부터 계속해요.
대본을 고쳐서 다시 저장하면, 바뀐 장면의 음성만 새로 만들어요.

### 결과물 위치

## 📂 소재 폴더 사용법

| 폴더 | 넣을 것 | 규칙 |
|---|---|---|
| `assets/my_footage` | 내가 직접 찍은 영상·사진 | 파일 이름을 내용이 드러나게. 같은 이름의 `.txt` 메모를 두면 매칭이 더 정확해요. |
| `assets/licensed` | 사용 허락을 받은 영상·사진 | **같은 이름의 `.license.txt` 허락 메모가 없으면 사용하지 않아요.** |
| `assets/bgm` | 무료 배경음악 (.mp3 등) | 유튜브 스튜디오 **오디오 보관함** 음원 추천 |
| `fonts` | 한글 폰트 (.ttf / .otf) | Pretendard, 나눔스퀘어 자동 인식 |

예시:
```
assets/my_footage/카페_라떼아트_latte_art.mp4
assets/my_footage/카페_라떼아트_latte_art.txt     ← "라떼 아트, 우유 거품, barista, coffee"
assets/licensed/서울야경_drone_seoul.mp4
assets/licensed/서울야경_drone_seoul.license.txt  ← 허락한 사람, 날짜, 범위
```

> 💡 대본을 만들 때 내 소재 목록이 Claude에게 전달돼서, 어울리는 장면에 "내 소재 우선"이 표시돼요.
> 💡 영어 단어도 파일명/메모에 넣으면 대본의 영어 검색어와 더 잘 맞아요.

## ⚖️ 저작권·정책 원칙 (꼭 읽어 주세요)

이 프로그램은 다음 원칙으로 만들어졌어요.

- ❌ **다른 사람의 유튜브 영상을 다운로드하거나 화면을 캡처해서 쓰는 기능은 없습니다.** (yt-dlp 같은 다운로더 미사용)
- ✅ 영상 소재는 딱 세 가지만 씁니다.
  1. 내가 직접 촬영한 영상·사진
  2. Pexels / Pixabay **공식 API** 로 받은 무료 라이선스 소재 (출처 자동 기록)
  3. 사용 허락을 받은 소재 (허락 메모 필수)
- ✅ 대본은 Claude가 **새로 쓴 창작물**이에요. 다른 영상의 스크립트를 복사·번역·재구성하지 않도록 지시되어 있어요.
- ✅ 리서치는 숫자(조회수·구독자·제목)만 보고 "어떤 주제에 수요가 있는지"만 파악해요.

업로드 전 체크리스트:
- [ ] `credits.txt` 내용을 영상 설명란에 붙여넣었나요?
- [ ] 배경음악이 출처 표기를 요구하면 설명란에 적었나요?
- [ ] 대본의 사실 정보(수치, 날짜 등)를 한 번 확인했나요?
- [ ] AI 음성·합성 콘텐츠라면 유튜브 업로드 시 **"변경되거나 합성된 콘텐츠"** 표시 정책을 확인했나요?

## ❓ 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `install.bat` 에서 "파이썬을 찾지 못했어요" | 1단계를 다시 하고, **Add python.exe to PATH** 체크를 꼭 켜세요. |
| "○○ 키가 없어요" | `.env` 파일에 키를 넣고 저장 → 검은 창 닫기 → `run.bat` 다시 실행. |
| "쿼터를 다 썼어요" (리서치) | 유튜브 무료 한도 초과. 다음 날(한국 시간 오후 4~5시 초기화) 다시 하거나 결과 수를 줄이세요. |
| 자막 한글이 □□□ 로 나와요 | `fonts` 폴더에 Pretendard 폰트를 넣으세요. |
| 영상 만들기가 너무 오래 걸려요 | ⑥ 탭에서 **720p** 로 먼저 미리보기 → 괜찮으면 1080p. `config.yaml` 의 `preset: veryfast` 도 효과 있어요. |
| 내레이션 생성 실패 (edge-tts) | 인터넷 연결 확인 후 다시 시도. 회사·학교 네트워크에서는 막혀 있을 수 있어요. |
| 장면에 단색 화면만 나와요 | Pexels/Pixabay 키를 넣거나, `assets/my_footage` 에 소재를 넣고 ④ 탭에서 **처음부터 다시 찾기**. |
| "영상 파일을 쓰는 중 문제" | 결과 영상을 플레이어에서 열어 둔 상태면 닫고 다시 시도하세요. |
| 그 밖의 오류 | 화면의 빨간 상자와 "자세한 내용"을 캡처해서 질문하세요. |
