How to Order

주문은 이렇게 진행됩니다

현재는 예약 신청과 문의를 받은 뒤, 농장에서 직접 확인 연락을 드리는 방식으로 운영합니다.

  1. 예약·문의 신청

    원하시는 등급과 수량, 받으실 시기를 남겨 주세요.

  2. 농장 확인 연락

    물량과 가격, 결제 방법을 직접 안내해 드립니다.

  3. 수확·선별

    등급 기준에 맞춰 고르고 중량을 확인해 담습니다.

  4. 발송·수확 정보 안내

    발송일과 수확 정보를 함께 알려 드립니다.
