# 청남대 대추 정원 공식 홈페이지

충북 청주시 상당구 문의면 **대왕사과대추** 농장 브랜드 홈페이지입니다.
설치할 것이 없는 정적 웹사이트(HTML·CSS·JS)라서 어떤 웹호스팅에도 그대로 올릴 수 있습니다.

## 바로 보기

```bash
cd website
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 더블클릭해도 열리지만, 폼 동작 확인은 위처럼 서버로 여는 것을 권장합니다.

## 페이지 구성

| 파일 | 내용 |
|---|---|
| index.html | 메인 (메인 비주얼, 브랜드 약속, 등급 요약, 정보 공개, 주문 절차, 예약·선물, 보관, 소식·FAQ) |
| brand.html | 브랜드 스토리 |
| product.html | 대왕사과대추 상품 안내 · 구매/배송 |
| grade.html | 상품 등급 안내 · 등급 기준표 |
| reserve.html | 수확 전 예약 신청서 · 수확 알림 신청 |
| gift.html | 선물 세트 안내 |
| quality.html | 품질 정보 공개 원칙 · 상품 관리 · 교환/환불 |
| storage.html | 대추 보관 및 이용 안내 |
| faq.html | 자주 묻는 질문 (FAQ 구조화 데이터 포함) |
| news.html | 공지사항 및 농장 소식 |
| contact.html | 고객 문의 |
| privacy.html | 개인정보 처리방침 (초안) |
| terms.html | 이용약관 (초안) |

## 수정하는 방법

1. 본문은 `_pages/*.html`에서 고칩니다. (루트의 `*.html`은 자동 생성물이니 직접 고치지 마세요.)
2. 사업 정보는 `build.py` 맨 위 `SITE`에 입력합니다.
3. `python3 build.py`를 실행하면 모든 페이지에 공통 헤더·푸터가 반영됩니다.

## 오픈 전 꼭 채워야 할 정보 (현재 '등록 예정'으로 표시됨)

확인되지 않은 정보는 홈페이지에 지어내 넣지 않았습니다. 아래 값이 정해지면 입력하세요.

- [ ] 대표자, 사업자등록번호, 통신판매업 신고번호, 상세 주소 — 전자상거래법상 쇼핑몰 하단 표시 의무 항목
- [ ] 전화번호, 이메일, 카카오톡 채널 주소
- [ ] 개인정보 보호책임자, 방침·약관 시행일, 택배사(개인정보 처리 위탁 업체)
- [ ] 등급별 한 알 중량·크기 범위, 상자당 개수 → `_pages/grade.html` 표
- [ ] 상품 중량 구성·가격·배송비 → `_pages/product.html`, `_pages/gift.html`
- [ ] 실제 사진 → 각 페이지의 `photo-slot`(“사진 교체 예정”) 자리를 `<img src="assets/img/파일.jpg" alt="설명">`으로 교체
- [ ] 도메인 → `SITE["base_url"]` 입력 시 canonical 주소와 `sitemap.xml` 자동 생성
- [ ] 개인정보 처리방침·이용약관 → 공개 전 전문가 검토 권장

## 예약·문의 폼 연결

지금은 폼 내용을 받아 줄 서버가 없습니다. 그래서 신청 버튼을 눌러도 **'접수 완료'로 표시하지 않습니다.**
대신 고객이 입력한 내용을 정리해 보여 주고, 복사하거나 이메일로 보낼 수 있게 안내합니다.

실제로 접수를 받으려면 [Formspree](https://formspree.io) 같은 폼 접수 서비스에서 주소를 발급받아
`SITE["form_endpoint"]`에 넣고 다시 빌드하세요. 그러면 신청 내용이 그 서비스로 전송되고 '접수되었습니다'가 표시됩니다.

## 결제

홈페이지에는 결제 기능이 없으며, 페이지에도 그렇게 안내되어 있습니다.
스마트스토어 등 결제 가능한 판매 채널을 열면 `SITE["store_url"]`에 주소를 넣으세요. 고객 문의 페이지에 연결 버튼이 생깁니다.
